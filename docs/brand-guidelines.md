| Name | Hex | RGB | Usage |

## 3. Voice & Tone

### Brand Personality

| Trait | Description |
|-------|-------------|
| **Precise** | Accurate timestamping, exact caption alignment |
| **Creative** | Expressive video styling, rich animations, unique fonts |
| **Helpful** | Frictionless workflow from upload to export |
| **Professional** | Enterprise-grade reliability and output quality |
